# Calendar Connector

Объединяет несколько Google-календарей с разных аккаунтов в один календарь, который
можно расшарить людям (полностью или только «занят/свободен»). Работает бесплатно на
Google Apps Script: свой сервер не нужен, ноутбук может быть выключен.

- Архитектура, модули и порядок подключения аккаунтов: [docs/PLAN.md](docs/PLAN.md)
- Быстрый старт (macOS, всё ставится внутрь папки проекта):

```
make setup                     # локальные Node и clasp
make test
make login  ACCOUNT=personal   # вход в Google (браузер)
make create ACCOUNT=personal   # создать скрипт в аккаунте
make push   ACCOUNT=personal   # выложить код
make app    ACCOUNT=personal   # ссылка на веб-интерфейс
```

## Поддержка

- **Ничего делать не нужно.** Скрипты работают в Google-аккаунтах и запускаются каждые
  5 минут сами.
- **Новый семестр или новый календарь.** Новые календари сами не подключаются: открой
  интерфейс нужного аккаунта (`make app ACCOUNT=...`), отметь их и нажми «Сохранить».
  Старые предметы можно снять: их копии удалятся.
- **Проверка.** Иногда открывай интерфейс: у каждого источника есть статус последнего
  прогона, красный означает ошибку (текст виден при наведении).
- **Обновление кода.** `make push ACCOUNT=personal` и `make push ACCOUNT=kse`. Если Google
  попросит новые разрешения, открой интерфейс и выдай их.
- **Папка проекта** нужна только для правок кода. Если её удалить, скрипты продолжат
  работать.
- **Полностью выключить:** удалить проекты «Calendar Connector (...)» на
  https://script.google.com/home в каждом аккаунте, затем при желании сам календарь
  «United Calendar».
